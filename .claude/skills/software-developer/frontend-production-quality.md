# Skill: Frontend Production Quality

Load this skill when implementing any user-facing UI, as a checklist for
what "done" means beyond "it builds."

## Priorities, in order

1. Fidelity to the agreed design
2. Accessibility
3. Responsive behavior
4. Maintainability
5. Performance
6. Simplicity

## Building

Use semantic HTML, reusable components, predictable state, clean data
flow, meaningful naming, minimal duplication. Do not create an
abstraction before the repeated pattern is actually understood.

## Content

Use realistic content and realistic lengths while implementing, not
Lorem Ipsum or placeholder text that hides real layout problems. Design
explicitly for: short titles, long titles, missing images, long labels,
error states, empty states.

## Before calling it done

Check visual fidelity at desktop, tablet, and mobile widths — not just
the width you happened to develop at.
