# Skill: Proposing a Visual Direction

Load this skill when a UI-heavy feature or product has **no** existing
design direction to follow — no client mockups, no established design
system — and a direction must be proposed before implementing. Skip it
entirely when the project already has one; do not invent a new direction
on top of an existing system.

## Method

Propose 3 genuinely different directions, not 3 variations of the same
look. For each, define: name, emotional effect, typography, palette,
composition, imagery, shape language, motion, component treatment, and
risks.

The three must differ in typography, density, composition, color
strategy, and visual metaphor — not just accent color.

## Selection

Select one based on strategic fit for the audience and positioning (not
personal preference), and write a short brief that stays consistent
through implementation:

```markdown
## Direction: <name>
Emotion: ...
Typography: ...
Palette: ...
Composition: ...
Imagery: ...
Shape language: ...
Motion: ...
Avoid: ...
```

Reference `premium-design-constitution.md` for the anti-generic-default
list before finalizing.
